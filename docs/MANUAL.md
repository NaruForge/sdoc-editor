# SDOC 에디터 기능 안내서

현재 `main`의 VS Code 확장에서 제공하는 기능을 한눈에 확인하는 안내서입니다.
SDOC는 `.sdoc`과 레거시 `.tiptap.json`을 구조를 유지한 채 편집합니다.

## 시작하기

1. 명령 팔레트에서 `Structured Doc: New .sdoc Document`를 실행하거나 기존 `.sdoc`/`.tiptap.json` 파일을 엽니다.
2. 본문은 에디터에서 입력하고, 서식은 도구 모음·버블 메뉴·컨텍스트 메뉴에서 선택합니다.
3. `Ctrl+S`(`Cmd+S`)로 저장합니다.

## 기본 편집과 서식

- 본문 입력, 선택, 복사·붙여넣기, 줄바꿈, 실행 취소·다시 실행을 지원합니다.
- 제목은 본문과 H1–H6 사이에서 바꿀 수 있습니다. 제목의 자동 번호 제외, 섹션 접기/펴기도 지원합니다.
- 텍스트 서식: **굵게**, *기울임*, 밑줄, 취소선, 인라인 코드, 텍스트 색상, 하이라이트, 아래 첨자, 위 첨자
- 문단 정렬: 왼쪽, 가운데, 오른쪽, 양쪽 정렬
- 목록: 글머리 목록, 번호 목록, 중첩 목록, 할 일 목록(체크박스)
- 블록: 인용문, 콜아웃(메모·정보·팁·주의·위험), 수평선, 코드 블록
- 자주 쓰는 단축키: `Ctrl/Cmd+B` 굵게, `Ctrl/Cmd+I` 기울임, `Ctrl/Cmd+U` 밑줄, `Ctrl/Cmd+K` 링크
- 커서 이동 기록: `Alt+←` 이전 위치, `Alt+→` 다음 위치

## 구조 탐색

왼쪽 탐색 패널에서 다음 목록을 열 수 있습니다.

| 패널 | 기능 |
|---|---|
| 목차 | H1–H6 제목을 자동으로 모아 해당 위치로 이동 |
| 그림 | 이미지와 그림 번호를 목록으로 표시 |
| 표 | 표와 표 번호를 목록으로 표시 |

제목·그림·표·수식의 번호와 내부 참조는 문서 구조에 맞춰 자동으로 갱신됩니다.

## 표

- `삽입 → 표`에서 3×3, 5×5, 7×7, 10×10 표 또는 사용자 지정 크기(행·열 각 1–50)를 삽입합니다.
- 머리글 행 전환, 위·아래 행 추가, 앞·뒤 열 추가, 행·열·표 삭제를 지원합니다.
- 병합 셀을 포함한 표를 표시하고 편집할 수 있습니다.
- 표 캡션, 왼쪽·가운데·오른쪽 정렬, 자동·50%·75%·100% 너비를 설정할 수 있습니다.
- 표가 화면보다 넓으면 표 전용 가로 이동 영역을 사용합니다. `←`·`→`, `Home`·`End`로 이동하고 `Enter`로 보이는 셀을 편집합니다.

## 이미지와 Draw.io

- workspace 이미지 삽입, 클립보드 이미지 붙여넣기, 기존 이미지 교체를 지원합니다.
- 이미지 캡션, 대체 텍스트, 왼쪽·가운데·오른쪽 정렬을 지정할 수 있습니다.
- 이미지의 속성 보기, 경로 복사, 삭제를 지원합니다.
- Draw.io 다이어그램은 새로 만들거나 기존 `.drawio.svg` 파일을 가져올 수 있습니다.
- Draw.io 이미지를 더블 클릭하면 Draw.io Integration 확장에서 원본을 열어 편집할 수 있습니다.

## 코드, 수식, 다이어그램

- 코드 블록: 코드를 직접 편집하고 언어를 선택합니다. 언어 자동 감지와 구문 강조를 지원합니다.
- 수식: LaTeX를 인라인 수식 또는 블록 수식으로 삽입하고, 입력 중 KaTeX 미리보기를 확인합니다.
- 텍스트 다이어그램: Mermaid, PlantUML, D2, Graphviz를 지원합니다.
  - Mermaid는 로컬에서 렌더링합니다.
  - PlantUML·D2·Graphviz 미리보기와 내보내기는 설정한 외부 renderer로 원문을 보낼 때 먼저 동의를 받습니다.
  - 다이어그램 설정에서 renderer 주소를 바꾸고 연결을 테스트하거나 private network 사용을 허용할 수 있습니다.
  - renderer를 사용할 수 없거나 동의하지 않으면 원문을 보존한 source-only 상태로 계속 편집할 수 있습니다.

## 링크, 교차 참조, 각주

- 웹·이메일·전화·다른 문서·문서 내부 링크를 삽입하고 수정·열기·복사·삭제할 수 있습니다.
- 링크 대화상자에서 다른 `.sdoc` 파일을 고르고 특정 제목·그림·표·수식을 대상으로 지정할 수 있습니다.
- 본문에서 `@`를 입력하거나 `삽입 → 교차 참조`를 선택하면 제목·그림·표·수식 목록에서 대상을 고를 수 있습니다.
- 교차 참조의 표시 번호와 라벨은 대상의 제목·캡션·번호가 바뀌면 함께 갱신됩니다.
- `삽입 → 각주`로 본문에 번호 표시를 넣고 문서 끝에서 한 줄 텍스트로 각주 내용을 편집합니다. 표시와 각주 목록은 서로 이동할 수 있습니다.

## 문서 정보와 디자인

- 문서 제목, 작성자, 버전을 편집하고 생성일·수정일을 확인할 수 있습니다.
- 디자인·내보내기 설정에서 다음 항목을 설정할 수 있습니다.
  - 제목 번호 표시, 시작 번호, 제목 장식, H1–H6 색상
  - 캡션 형식: IEEE, ISO/IEC, Modern, 한국식
  - 캡션 번호와 수식 번호: 순차식 또는 계층식
  - 교차 참조에 캡션 포함 여부
  - HTML/PDF 자체 포함 방식, PDF 배율, 출력 폴더
  - 슬라이드 분할 기준, 제목 슬라이드, 전환 효과
  - HTML용·슬라이드용 사용자 CSS 파일
- 화면 설정: UI 언어 자동/한국어/영어, 제목 번호·장식의 임시 표시 방식, 60–200% 확대/축소, 읽기 너비(좁게·편안하게·넓게·전체)

## 템플릿

- 내장 템플릿: 빈 문서, 기능 둘러보기, 기술 보고서, 설계 명세서, 시험·검증 보고서
- workspace 템플릿: `.sdoc/templates/*.sdoc`에 저장하여 팀과 공유
- 개인 템플릿: `~/.sdoc/templates/`에 저장
- 검색·카테고리 필터·구조 미리보기를 지원합니다.
- 템플릿으로 새 문서를 만들거나 현재 문서에 적용할 수 있습니다. 현재 문서 교체 전에는 확인 대화상자가 표시됩니다.
- 현재 문서를 템플릿으로 저장하고, 개인 템플릿을 수정·복제·삭제하거나 템플릿 폴더를 열 수 있습니다.

## 가져오기와 내보내기

파일 패널에서 다음 형식을 사용할 수 있습니다.

| 방향 | 형식 |
|---|---|
| 가져오기 | Markdown, HTML |
| 내보내기 | HTML, PDF, Markdown, AsciiDoc, Slides(reveal.js) |

실행 전에는 원본·대상·적용 설정·덮어쓰기 여부를 확인합니다. 실행 중 취소, 실패 시 재시도, 완료 후 결과 파일 열기·위치 보기·경로 복사·다시 실행을 사용할 수 있습니다.

고급 메뉴에서 현재 문서의 원본 JSON을 열어 구조를 확인할 수 있습니다.

가져오기는 본문만 교체하고 문서 메타데이터와 설정은 유지합니다. 가져온 내용은 문서를 저장해야 파일에 기록됩니다.

## 여러 문서 묶기: `.sdocbook`

- 여러 `.sdoc`을 장 순서대로 묶고, 장을 추가·열기·순서 변경·삭제할 수 있습니다.
- Book 제목·작성자·버전, 전체 목차, 진단 결과, 통합 미리보기를 제공합니다.
- Publish 프로필에서 번호·캡션·HTML 포함 방식·PDF 배율·다이어그램 실패 정책·CSS·출력 폴더를 정한 뒤 HTML/PDF로 내보냅니다.
- `.sdocbook` 작업공간은 현재 VS Code에서 제공합니다. 1.0 Book은 미리보기/편집은 가능하지만 내보내기는 차단되며, 1.1 프로필을 저장해야 내보낼 수 있습니다.
- 단일 문서 각주는 Book 합성 정책이 정해질 때까지 Book 합성에서 지원하지 않습니다.

## 저장과 안전성

- `.sdoc`은 메타데이터와 구조화된 문서 트리를 저장합니다.
- 잘못된 JSON이나 지원하지 않는 미래 버전은 빈 문서로 덮어쓰지 않고 진단과 원본 JSON 열기를 제공합니다.
- 외부에서 문서가 바뀌면 변경 내용을 비교한 뒤 내 변경 유지 또는 외부 버전 다시 불러오기를 선택합니다.
- 이미지와 Draw.io 자산은 문서 기준 상대 경로로 관리하며, 문서 밖 경로와 안전하지 않은 링크는 거부합니다.
- VS Code 설정에서 새 이미지의 기본 정렬과 내보내기 이미지 경로(상대·절대)를 지정할 수 있습니다.
- 읽기 전용 문서에서는 내용과 구조를 변경할 수 없습니다.

## CLI 자동화

시각 편집이 아닌 자동화가 필요하면 [CLI 매뉴얼](../cli/README.md)을 참고하세요. CLI는 문서 생성·검사·검증·구조 조회·교차 참조 조회·안전한 의미 연산을 preview-first 방식으로 제공합니다.
